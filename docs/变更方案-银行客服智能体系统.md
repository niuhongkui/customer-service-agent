# 变更方案：基于 CrewAI 的多角色银行客服智能体系统

## 一、项目概述

基于 CrewAI 搭建多角色银行客服智能体集群，利用 Plan&Execute 规划模式完成客户咨询任务拆解，通过 ReAct 推理执行链路实现思考、调用工具、结果校验的完整闭环。依托 LlamaIndex 构建银行业务专属 RAG 知识库，接入 Milvus 向量数据库做语义召回，精准回复各类银行客服问题。

## 二、技术选型

| 组件 | 选型 | 说明 |
|------|------|------|
| API 框架 | FastAPI | 异步支持好，自带 OpenAPI 文档 |
| Agent 框架 | CrewAI | 支持 Plan&Execute 和 ReAct 模式 |
| RAG 框架 | LlamaIndex | 文档索引与语义检索 |
| 向量数据库 | Milvus Lite | 嵌入式，无需独立服务 |
| Embedding 模型 | BGE（bge-large-zh） | 中文语义理解，可本地部署 |
| 大语言模型 | Ollama + Llama 3.2 | 本地部署，数据不出境 |
| 包管理 | uv | 快速 Python 依赖管理 |
| 部署 | Docker Compose + 本地开发 | 混合模式 |

## 三、系统架构

```
用户请求
   ↓
FastAPI (/chat)
   ↓
CrewAI Orchestrator
   ├── Triage Agent（分诊员）
   │      ├── → Account Agent（账户专家）
   │      └── → Financial Advisor Agent（理财顾问）
   ↓
LlamaIndex RAG Pipeline
   ↓
Milvus Lite（向量检索）
   ↓
Ollama + Llama 3.2（生成回复）
```

## 四、智能体角色定义

### 4.1 Triage Agent（分诊员）
- **职责**：解析用户意图，将请求路由到对应专家
- **工具**：意图分类工具
- **行为**：Plan&Execute 模式，先规划再执行

### 4.2 Account Agent（账户专家）
- **职责**：处理账户查询、转账汇款、挂失安全、投诉工单
- **工具**：RAG 检索工具、模拟账户查询工具、模拟转账工具
- **行为**：ReAct 模式，思考→调用工具→校验结果

### 4.3 Financial Advisor Agent（理财顾问）
- **职责**：处理理财产品咨询、信用卡服务、贷款咨询、风险评估
- **工具**：RAG 检索工具、产品查询工具
- **行为**：ReAct 模式，思考→调用工具→校验结果

## 六、RAG 知识库设计

### 6.1 文档来源
- 格式：Word / Markdown
- 内容：产品规章、业务流程文档

### 6.2 切片策略
- 按语义段落切片
- 保留标题层级结构
- 每个切片包含所属章节上下文

### 6.3 向量化流程
```
Word/Markdown 文档
   ↓ LlamaIndex 文档加载器
   ↓ 语义段落切分
   ↓ BGE Embedding（bge-large-zh）
   ↓
Milvus Lite 存储
```

### 6.4 反幻觉策略
- Prompt 中明确要求"仅基于检索到的文档内容回答"
- 对检索结果进行相关性评分，低分结果降权
- 回复中标注信息来源

## 七、Plan&Execute + ReAct 流程

### 7.1 Plan&Execute（Triage Agent）
1. **Plan 阶段**：分析用户请求，制定处理计划（路由到哪个专家）
2. **Execute 阶段**：将请求转发给对应 Agent

### 7.2 ReAct（Account / Financial Advisor Agent）
1. **Thought**：分析需要什么信息，决定调用哪个工具
2. **Action**：调用 RAG 检索或业务工具
3. **Observation**：获取工具返回结果
4. **Thought**：校验结果是否充分，是否需要继续调用
5. **Answer**：生成最终回复

## 十二、风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| Ollama + Llama 3.2 本地推理速度慢 | 响应延迟高 | 使用轻量 prompt，限制上下文长度 |
| Milvus Lite 数据量上限 | 知识库容量受限 | 先验证流程，后续可迁移到 Standalone |
| Llama 3.2 中文能力不如 Qwen | 回复质量下降 | 对比测试，必要时切换模型 |
| Agent 路由错误 | 用户咨询被错误分发 | Triage Agent 增加置信度校验 |
