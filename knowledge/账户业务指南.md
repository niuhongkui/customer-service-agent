# 账户业务指南

## 账户查询

### 余额查询

客户可通过以下方式查询账户余额：

1. **手机银行**：登录手机银行 APP，进入「账户管理」→「余额查询」
2. **网上银行**：登录网上银行，进入「我的账户」→「账户概览」
3. **ATM**：插入银行卡，选择「余额查询」
4. **柜台**：携带身份证和银行卡到任意网点办理

### 交易明细查询

- 手机银行可查询近 2 年的交易记录
- 网上银行可查询近 5 年的交易记录
- 柜台可查询开户以来的全部交易记录
- 查询时间范围超过 3 个月可能需要支付查询手续费（¥5/次）

## 转账汇款

### 行内转账

- **到账时间**：实时到账
- **手续费**：免费
- **单笔限额**：¥500,000
- **日累计限额**：¥1,000,000

### 跨行转账

- **到账时间**：一般 1-2 个工作日
- **手续费**：
  - 转账金额 ≤ ¥10,000：¥2/笔
  - ¥10,000 < 转账金额 ≤ ¥50,000：¥5/笔
  - 转账金额 > ¥50,000：转账金额的 0.1%，最高 ¥50/笔
- **单笔限额**：¥500,000
- **日累计限额**：¥1,000,000

### 转账注意事项

1. 请确认收款人姓名和账号准确无误
2. 跨行转账请确认收款行信息
3. 大额转账建议提前预约
4. 转账后保留交易凭证

## 账户安全

### 密码管理

- 交易密码为 6 位数字
- 建议每 3 个月修改一次密码
- 不要使用生日、电话号码等容易被猜到的数字

### 密码重置

如忘记交易密码，可通过以下方式重置：

1. **手机银行**：通过人脸识别 + 短信验证码重置
2. **柜台**：携带身份证和银行卡办理密码重置

### 账户冻结

如银行卡丢失或被盗，请立即申请冻结：

1. **电话银行**：拨打 95588，通过身份验证后申请冻结
2. **手机银行**：进入「安全中心」→「账户冻结」
3. **柜台**：携带身份证办理

冻结后如需解除冻结，需本人携带身份证和银行卡到柜台办理。
